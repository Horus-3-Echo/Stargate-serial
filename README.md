# Stargate-serial

Dlouhodobý seriálový sci-fi projekt inspirovaný základní myšlenkou hvězdné brány, ale budovaný jako vlastní konzistentní univerzum.

## Stav projektu

Projekt je plánován na 10+ sérií. Výchozí období je konec 90. let na Zemi našeho světa. Program hvězdné brány začíná jako tajný americký projekt a jeho existence se může odtajnit až později.

Důraz je na pomalý vývoj, dlouhodobé následky, kontinuitu a hard-SF až hardish-SF přístup. Země není středem galaxie ani přirozeně nejvýznamnější civilizací.

## Hlavní pravidlo kánonu

GitHub repozitář je trvalý zdroj pravdy projektu. Nové epizody, technologie, postavy, světy a dějové oblouky mají být kontrolovány proti existujícím souborům v repozitáři.
